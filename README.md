# بدايات كلود: مهارات الفيديو والتصميم

هاي المهارات اللي بتحتاجها عشان تبلّش تعمل فيديوهات وتصاميم بكلود.

— أسامة جمال AI

## قبل ما تبلّش
1. **اشتراك Claude Pro** (20 دولار بالشهر)
2. **تطبيق Claude** على الكمبيوتر: [claude.ai/download](https://claude.ai/download)
3. بالتطبيق افتح تبويب **Code**، وهاد هو **Claude Code** اللي بتشتغل عليه المهارات

## أسهل طريقة للتثبيت
افتح Claude Code وابعتله هالجملة:
> ثبّتلي المهارات اللي بهالصفحة: https://github.com/osama-jamal-ai/mahara-reels

وهو بيثبّتهم كلهم لحاله.

## 1. مهارات الفيديو

بيشتغلوا على **Claude Code**، وبيحتاجوا برامج على الجهاز (ffmpeg وNode.js وPython)، وكلود بيثبّتهم إلك.

### Motion Reel: موشن غرافيك من الصفر
فيديوهات موشن بدون ما تصوّر إشي: نصوص متحركة، وأشكال، وموسيقى وأصوات، وبتطلّع الفيديو عمودي للريلز. هاي الأقرب لستايل فيديوهاتي.

اكتب هدول بـ Claude Code، واحد ورا التاني:
```
/plugin marketplace add aries-spring/motion-reel
```
```
/plugin install motion-reel@aries-spring
```

### IT Reelsmaker: منتاج الفيديو المصوّر
إذا صوّرت حالك وإنت عم تحكي: بتقصّ السكتات والغلطات، بتعمل ترجمة كلمة بكلمة، وبتضيف موشن غرافيك.
```
/plugin marketplace add itpartypattaya/reels-montage
```
```
/plugin install it-reelsmaker@itparty
```

## 2. مهارات بدايات التصميم

### Frontend Design (الرسمية من Anthropic)
بتخلّي كلود يعمل تصاميم صفحات وبوسترات وواجهات بجودة عالية، مش شكل "AI".
```
/plugin install frontend-design@claude-plugins-official
```

### Canva
بتعمل وبتعدّل تصاميم Canva مباشرة من كلود (بدك حساب Canva).
```
/plugin marketplace add canva-sdks/canva-skills
```
```
/plugin install canva@canva-skills
```
