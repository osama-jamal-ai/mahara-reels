# مهارة الريلز: اعمل ريل كامل بكلود

هاي المهارة اللي عملت فيها الفيديو. بتعلّم كلود يعمل ريل عمودي بستايل ورقي: عنوان فوق بيمشي مع صوتك كلمة بكلمة، وخطوات مرقّمة، ورسومات بسيطة، وبيطلّعلك MP4 جاهز.

— أسامة جمال AI

## شو بتحتاج
1. **اشتراك Claude Pro**، وتطبيق **Claude** على الكمبيوتر (من claude.ai/download)
2. **Claude Code**: من التطبيق افتح تبويب **Code**
3. مجلد فاضي للمشروع على الكمبيوتر

## التثبيت (مرة وحدة)

**أسهل طريقة:** افتح Claude Code بمجلد فاضي، وابعتله هالجملة:
> ثبّتلي المهارة من https://github.com/osama-jamal-ai/mahara-reels بمجلد المهارات، وثبّت كل البرامج اللي بتحتاجها (Node وffmpeg وPython)

وهو بيعمل كل إشي لحاله.

**أو يدوي:**
1. فوق بهالصفحة اضغط الزر الأخضر **Code** ← **Download ZIP**
2. فك الضغط، وغيّر اسم المجلد من `mahara-reels-main` لـ `mahara-reels`
3. انسخ المجلد لمجلد المهارات:
   - **Windows:** `C:\Users\<اسمك>\.claude\skills\`
   - **Mac:** `~/.claude/skills/`
   (إذا مجلد `skills` مش موجود، اعمله)
4. سكّر Claude وافتحه من جديد

## الاستعمال
بتحكيله سطر واحد، مثلاً:
> صمّملي ريل 30 ثانية عن [الموضوع]، بلهجتي، وآخر إشي "علّق كلمة X"

وهو بيكتب السكريبت، وبيستناك توافق، وبعدها بيعمل التصميم وبيطلّع الفيديو.
